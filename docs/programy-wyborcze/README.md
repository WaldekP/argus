# Programy wyborcze partii sejmowych 2011-2023

## Rola korpusu

Surowiec źródłowy do analiz programowych: jak zmieniały się programy partii, które zdobywały
mandaty w wyborach do Sejmu w latach 2011, 2015, 2019 i 2023. Docelowo materiał pod plan
wyborczy dla tenanta pilotażowego (Ryszard Petru, elektorat wolnościowo-liberalny) oraz pod
pobieranie plików w aplikacji.

Wszystkie pliki pobrane 2026-07-25, każdy zweryfikowany (nagłówek `%PDF`, treść pierwszych
stron zgodna z tytułem). Tam, gdzie oryginalne strony partii już nie istnieją, źródłem jest
kopia w Web Archive (sufiks `id_` w URL daje surowy plik bez bannera archiwum) albo archiwum
Manifesto Project / Demagoga / mamprawowiedziec.pl / ISP PAN.

Decyzja usera (2026-07-25): Mniejszość Niemiecka pominięta jako nieistotna dla celu korpusu
(pliki usunięte z repo; w 2023 komitet zresztą nie zdobył mandatu).

## Zasady pracy

- To korpus surowców (PDF-y źródłowe), nie baza wiedzy. Analizy i opracowania tematyczne
  budujemy w osobnych katalogach `docs/` według konwencji projektu.
- Przy cytowaniu zawsze podawaj partię, rok i tytuł dokumentu. Liczby i obietnice weryfikuj
  w pliku źródłowym, nie z pamięci modelu.
- Ponowne pobieranie: curl na Windows wymaga flagi `--ssl-no-revoke`; z Web Archive pobieraj
  z sufiksem `id_` po timestampie (surowe bajty, bez bannera).
